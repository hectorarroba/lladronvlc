LLADRÓN VLC — Web prototype

Open index.html in a modern browser to preview the responsive website.

CUSTOMIZE FIRST
- Palette, typography, spacing and borders: edit the CSS variables at the top of the <style> block in index.html.
- Logo: replace assets/logo-original.png with the final logo, then update the brand area in the header if you want to display the image directly.
- Video cards: each .video-card contains a thumbnail, title and metadata. Replace the CSS gradient placeholders with real poster images, and replace the modal preview in #videoModal with an HTML5 <video> or your Vimeo/YouTube embed.
- Contact: update hola@lladronvlc.com and the Instagram/TikTok links to the real accounts.
- The current video previews, durations, and project names are design placeholders, not real client work.

No framework or build step required. Plain HTML, CSS and JavaScript.
